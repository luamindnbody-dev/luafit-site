PDF 저장하는 법

아이폰 (Safari)
  1. 위 출력용 PDF 다운로드 버튼을 길게 꾹 눌러요.
  2. 뜨는 메뉴에서 공유를 눌러요.
  3. "파일에 저장"을 누르면 파일 앱에 저장돼요. (노트+·굿노트를 고르면 바로 열려요)

PDF가 이미 화면에 열렸다면: 주소창이나 아래 공유 버튼(□↑) → "파일에 저장"

안드로이드 (크롬·삼성 인터넷)
  1. 버튼을 한 번 눌러요. 바로 받아지면 끝이에요.
  2. PDF가 화면에 열리기만 하면, 오른쪽 위 ⋮ → 다운로드(↓)를 눌러요.
  3. 받은 파일은 내 파일 → 다운로드 폴더에 있어요.

카톡·인스타에서 열었다면 먼저 ⋯ → 다른(외부) 브라우저로 열기를 누른 뒤 위 방법대로 해 주세요.
